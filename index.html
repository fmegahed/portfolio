Projects

Calibrated Defect Detection Beyond CLIP

I worked with Ying-Ju Chen to compare structured decision models with few-shot CLIP for detecting defects in manufacturing images. We used shared image sets, calibrated probabilities, and paired tests on the same test images. The project includes R code for scoring and evaluation, tests, and a Quarto document that rebuilds its tables and figures from saved results. The work is ongoing.
